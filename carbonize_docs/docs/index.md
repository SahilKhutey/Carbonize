# Carbonize Documentation

Welcome to the Carbonize documentation portal. This is your comprehensive guide to deploying, operating, and developing the Carbonize carbon capture monitoring platform.

## What is Carbonize?
Carbonize is an AI-powered platform for monitoring carbon capture operations. It combines:
- Real-time sensor data ingestion
- ML-based anomaly detection (Autoencoders, Streaming Isolation Forest)
- Stream drift monitoring
- Robotic fleet management
- Chaos engineering for production resilience
